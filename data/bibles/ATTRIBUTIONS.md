# Open Bible sources included in Postmaker

The application reads the verse text for its built-in Scripture cards directly
from the unmodified USFM files below. The selected text is returned verbatim;
the app never asks an AI model to recreate these translations.

| UI id | Translation | Source | License |
| --- | --- | --- | --- |
| `synodal` | Russian Synodal Bible | https://ebible.org/details.php?id=russyn | Public Domain |
| `freedom` | Біблія свободи | https://ebible.org/details.php?id=ukrfb | Public Domain |
| `ubg` | Uwspółcześniona Biblia Gdańska | https://ebible.org/details.php?id=polubg | CC BY-ND 4.0 |
| `ytc` | Yorumsuz Türkçe Çeviri | https://ebible.org/details.php?id=turytc | CC BY-ND 4.0 |
| `obtt` | Open Basic Turkish New Testament | https://ebible.org/details.php?id=turobt | CC BY-SA 4.0 |

`CC BY-ND` texts are stored and shown without wording or punctuation changes.
`CC BY-SA` texts retain their required source attribution. The New Russian
Translation, Огієнка, Турконяка, Громова, Warszawska and Tysiąclecia are not
bundled because the verified sources do not grant a redistribution licence that
fits this application. They can be added after written permission or a licensed
Bible API key is provided.
